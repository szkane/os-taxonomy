# PEDAGOGY-AUDIT — representation coverage vs mainstream EN-language + IB teaching

The site's claim: every primary-school course (**304 courses across 66 domains, Ages 5–10 / Kindergarten to Grade 5**) teaches with the visual representations English-speaking curricula (England NC, Australian AC v9, US NGSS/CCSS, Ontario) and IB PYP practices actually use — never a generic quiz per topic.
