🎯 What you’ll learn

  • 📊Sorting into categories — Classify objects into given categories, count the number in each category, and sort the categories by count
  • 📊Pictograms and tally charts — Interpret and construct simple pictograms, tally charts, block diagrams, and simple tables, including giving displays a title, labels and the source of the data
📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is learning to organise and count information by sorting objects into groups and comparing which groups have more or fewer items.

Common misconceptions (from teaching research)

Sorting into categoriesShifts the sorting criterion partway — begins by colour then starts grouping by size or shape, ending with mixed pilesNext step: Name the one attribute aloud ('everything sorted by COLOUR') and re-sort together; hold up a counter and ask 'what colour — so which pile?' to fix the single rule
Pictograms and tally chartsIgnores the key and reads each symbol as one, so a many-to-one pictogram is read at half its value (and constructed with one symbol per item)Next step: Read the key aloud first every time; overlay the pictogram on a one-to-one version to show each symbol 'carries' 2; rebuild the fish row from the key

Activity ideas

  • Drag-to-sort (or hands-on sort) with self-counting groups
  • Sort the same set two different ways
  • Answer a real question from sorted class data
  • Two-way chart builder from the class's own data
