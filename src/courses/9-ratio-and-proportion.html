Common misconceptions (from teaching research)

Bar Models for RatiosDraws unequal blocks: makes the 5-bar blocks a different size from the 1-bar block, so the blocks no longer represent equal unitsNext step: Return to cubes: every block is one identical cube. Rebuild the given diagram with physical equal units before drawing again.
Percentages (age 9+)Uses 'ratio' and 'proportion' as if identical: 'the proportion of concentrate to water is 1:4' — applies part-to-part language to a part-to-whole comparison and vice versaNext step: Confront with the twin picture: 'ratio compares these two bars; proportion compares this part to the whole bar' — have the child re-describe each from its own picture, using the matching word.

Activity ideas

  • Build the tape diagram: draw, find one block, read off
  • Concrete first: build the ratio with cubes, then draw it
  • Read a worked bar model (scaffold)
  • Match, read and sketch (assessment-style practice)
