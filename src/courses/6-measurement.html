🎯 What you’ll learn

  • 📏Choosing measurement units — Choose and use appropriate standard units to measure length (m/cm), mass (kg/g), temperature (°C), and capacity (litres/ml) to the nearest appropriate unit
  • 📏Measuring length — Order three objects by length and compare the lengths of two objects indirectly using a third object
  • 📏Area (age 8+) — Measure areas by counting unit squares (square cm, square m, square in, square ft)

📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is learning practical measurement skills — reading clocks to five-minute intervals, measuring length and capacity using standard units, and working with money including making change.

Common misconceptions (from teaching research)

Choosing measurement unitsAttribute–unit mismatch: uses a tool or unit from the wrong attribute — reaches for a ruler to find 'how much water', or reports grams for a length — not first asking what kind of quantity this is.Next step: Name the attribute first (how long? how heavy? how much fills it? how hot?), then match the unit family; return to hands-on experience with the weak attribute (e.g. filling and pouring for capacity).
Measuring lengthNo transitive inference — pairwise only: sees the two far-apart objects as simply not comparable, or insists on carrying one object to the other, never using the string as a proxy for a length.Next step: Model matching the string to A, then to B, and voice the chain 'A vs string, string vs B, so A vs B'; secure direct comparison first so the intermediary has something to stand for.
Area (age 8+)Counts the boundary, not the interior: counts squares around the edge (perimeter) rather than the squares covering the surface.Next step: Return to what area means — the surface covered; shade the interior and count only covering squares, contrasting with the distance around.
Understanding AreaArea/perimeter confusion: judges 'bigger' by how far the shape stretches or the distance around its edge, so chooses the long strip.Next step: On congruent rectangles, mark the unit lengths around the perimeter of one and draw the square units inside the other, so the child sees area (surface covered) and perimeter (distance around) are different measures; then count squares to compare.
Comparing and ordering measurementsCompares bare numbers, ignoring units: judges by the digits alone, so '50 cm > 1 m because 50 is bigger', or '300 g > 1 kg'.Next step: Put both on a common scale/unit so the true sizes show; reinforce that the unit travels with the number and comparison needs a shared unit.
Number of minutes in an hourThinks a whole day is 12 hours because the clock face 'stops at 12' — doesn't realise the hour hand goes round twiceNext step: Confront it directly: track the hour hand through a full day, naming am then pm as two 12-hour sweeps, and line the 12-hour clock up against a 24-hour clock so 13:00 = 1pm.
