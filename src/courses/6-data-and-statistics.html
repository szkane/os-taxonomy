📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is learning to work with data — creating and reading simple charts, graphs, and tables to organise information and answer questions about what the data shows.

Common misconceptions (from teaching research)

Pictograms and tally charts (age 6+)Confuses discrete and continuous — calls height discrete because it's recorded as a whole number, or thinks 'continuous' just means 'lots of data'Next step: Apply the 'could there be a value in between?' test — someone can be 125.5 cm but not have 2.5 pets; contrast the pair explicitly
Sorting Data into CategoriesOrganises the data but cannot read it back to answer the original question (table as decoration)Next step: Model reading a table to answer a question ('the biggest number is beside…'); keep returning to the question so the table becomes a tool
Picture & Bar GraphsAnswers 'how many more' with the taller bar's value instead of the difference between the two barsNext step: Align the two bars and count the squares the taller one sticks up by; name 'how many more' as that gap, then re-ask
Sorting into categories (age 6+)Answers 'how many more chose dogs than cats' with the dogs value (8) instead of the difference (3)Next step: Line the two categories up one-to-one and count the unmatched part; name that 'how many more' means the gap/difference, then re-ask

Activity ideas

  • Label the chart and sort the data
  • Tally to frequency: marks become a count
  • Contrast-pair glossary (scaffold)
  • Survey organiser: from response cards to a table that answers the question
