🎯 What you’ll learn

  • 🍪One-to-one counting — One-to-one correspondence when counting objects: each object is paired with exactly one number name
  • 🍪How Many in Total? — Cardinality principle: the last number said when counting a set tells how many objects are in the set, regardless of arrangement or order counted
  • 🍪Comparing groups: more or fewer — Compare two groups of objects to determine which has more, fewer, or whether they are equal, using matching and counting strategies
  • 🍪One More Each Time — Each successive counting number represents a quantity that is one larger than the previous number
  • 🍪Two written numerals between 1 and 10 — Compare two written numerals between 1 and 10 to determine which is greater or less
  • 🍪Representing numbers with objects — Represent numbers using objects, pictorial representations, and the number line

Common misconceptions (from teaching research)

One-to-one countingtrusts the last word said no matter how the counting went ('he said seven, so there's seven') — thinks the answer is just whatever number you end onNext step: recount together slowly, sliding each button to one side as it gets its single number word, so one-word-per-object is visible
How Many in Total?last-word parroting — gives the final count word when asked 'how many' but doesn't treat it as the total; recounts when asked again, or cannot count out a requested amountNext step: play 'so how many?' games — count, then immediately ask the total and hide the set; add count-out tasks ('give me exactly 4') so the number becomes a stop-signal for a quantity
Comparing groups: more or fewerlength stands in for number — judges the longer or more spread-out row as 'more' regardless of count ('this one has more, it's longer')Next step: line the two rows up end-to-end and match one-to-one so the leftover counter is visible; count both aloud; then squeeze/spread a row to show number doesn't change with length
One More Each Timesays a number for 'one more' that isn't the successor — any bigger number, or a familiar landmark like 10 — doesn't map +1 to the very next wordNext step: reteach with concrete add-one-and-count on a number track, showing 7 then 8 is exactly one step along; anchor 'one more = next number'
Two written numerals between 1 and 10> / < reversal — knows which number is bigger but points the sign the wrong way; treats the symbols as decoration rather than 'open end faces the larger'Next step: the open mouth 'eats' the bigger number; always check by reading the finished statement aloud to catch the mismatch
Representing numbers with objectsnumber-line off-by-one — reads the marked point as 5 or 7 because they count the 0 tick as 'one', or count marks instead of the jumps between themNext step: count the JUMPS from 0 aloud, hopping a finger from 0; label 0 explicitly as the start, not a step

Try at home (predict–observe–explain)
