🎯 What you’ll learn

  • 🔺Using Simple Formulae — Use simple formulae expressed in words or symbols to calculate values (e.g. perimeter = 2 × (length + width))
  • 🔺Writing Algebraic Equations — Express missing number problems algebraically using letters for unknowns; translate word problems into equations
  • 🔺Number Pattern Relationships — Generate two numerical patterns using two given rules; identify relationships between corresponding terms; form ordered pairs and graph them on a coordinate plane
  • 🔺Equations with Two Unknowns — Find pairs of numbers that satisfy an equation with two unknowns (e.g. find pairs (a, b) where a + b = 10 or 2a + b = 15)
  • 🔺Linear number sequences — Generate and describe constant-step (linear) number sequences whose terms include negative values (counting through and past zero) or whose step is a decimal, using …
  • 🔺Systematic Listing — Enumerate possibilities of combinations of two variables systematically (e.g. all ways to choose from a set of options)
  • 🔺Designing number algorithms — Design and use algorithms with a sequence of steps, decisions with several alternatives (if / else-if / else) and repetition that apply rules to generate sets of …
📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is beginning to work with algebra — using letters to represent unknown numbers, creating and following rules for number patterns, and translating word problems into mathematical equations.

Common misconceptions (from teaching research)

Using Simple FormulaeOmits the ½ in a triangle's area — computes base × height and stops, giving the rectangle's area.Next step: Show the triangle as exactly half its enclosing rectangle by cutting/folding; stress that every operation written in the formula must be carried out.
Writing Algebraic EquationsReversal error by word-order matching — writes 4c = d for '4 times as many cats as dogs', mapping the words straight onto symbols left-to-right.Next step: Anchor to quantities: 'if there are 3 dogs, how many cats?' (12). Does 4c = d give that? Build a small table of values BEFORE writing the equation, then read the equation aloud to check it matches.
Number Pattern RelationshipsCompares the two sequences additively — 'Rule B is 6 more than Rule A' — instead of multiplicatively ('twice')Next step: Line up several corresponding pairs and ask 'is the gap the same or growing?'; the ×2 ratio is constant while the difference grows — compare 'how many times' not 'how many more', supported by a tape diagram
Equations with Two UnknownsTreats it like a single-answer equation — finds ONE pair and stops, as if a and b are unique unknowns to be solved forNext step: Show it is a whole family of solutions — 'is there another pair? and another?'; fix a and step it through its values to reveal them all
Linear number sequencesThinks the sequence 'stops' at zero — that you cannot go below zero or that negative numbers are not real, so 5, 3, 1 halts or ends at 0Next step: Confront with a temperature scale / number line with zero central and keep the equal hop going; below-zero numbers are real positions to the left of zero
Systematic ListingLists haphazardly — random pairings, so meals are missed or duplicated and completeness cannot be judgedNext step: Hold one category fixed and run through the other in order; record in a grid so gaps show — 'found them all because I worked systematically'
