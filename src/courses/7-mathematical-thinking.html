🎯 What you’ll learn

  • 🧠Multi-Step Problem Solving — With teacher support, make sense of multi-step problems involving larger numbers or mixed operations by breaking them into parts, choosing strategies, and checking …
  • 🧠Understanding fractions (age 7+) — Communicate with mathematical precision: use correct place-value and fraction vocabulary, specify units in measurement answers, and use notation accurately
  • 🧠Justifying mathematical reasoning — Construct and follow multi-step mathematical arguments; identify errors in reasoning and explain why a method works or does not work
  • 🧠Choosing the right strategy — Select and use appropriate tools and representations strategically, including choosing between mental methods, jottings, formal algorithms, and calculators for …
  • 🧠Shape patterns (age 7+) — Look for and use mathematical structure: apply place-value patterns to three-digit operations, use multiplication/division relationships, and exploit shape properties to …
  • 🧠Extending Table Patterns — Recognise and use repeated reasoning to generalise: extend multiplication table patterns, derive unknown facts from known ones, and describe rules for sequences
📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is learning to think like a mathematician — solving multi-step problems, explaining their reasoning, recognising patterns in numbers, and choosing the best tools and strategies for different mathematical challenges.

Common misconceptions (from teaching research)

Multi-Step Problem SolvingBelieves that if the first method doesn't work, you're stuck — does not switch strategy or representation.Next step: Model 'change course if necessary' — show two ways to represent the same problem and name switching as a normal part of solving; prompt 'what's another way we could show this?'.
Understanding fractions (age 7+)Omits or is inconsistent with units — writes '35' for a length that is 35 cmNext step: Insist the unit is part of the answer; contrast 35 cm with 35 m and 35 mm so the unit visibly changes the meaning. Reteach calculating with standard units.
Justifying mathematical reasoningEmpirical proof scheme — treats a few confirming examples as proof that a general statement holds for all cases.Next step: Accept examples as illustration, then explicitly model the move to a general/generic argument ('how do we know for a pair we haven't tried?'); use the pairs structure of even numbers. Name that examples illustrate but do not prove — a key development, not a failing.
Choosing the right strategyApplies the formal written method to everything, even 345+200 or 300+300, because it is the 'proper' wayNext step: Sort a mixed set into 'do in your head' vs 'worth writing down'; ask what the numbers let you SEE (the +200). Build the habit of reading before routing — reteach in place, this is a strategy-selection issue not a gap in the algorithm.
Shape patterns (age 7+)Treats multiplication and division as unrelated operations, recomputing 24÷4 from scratch despite just stating 6×4=24Next step: Return to one array and physically read all four facts from it (rows, columns, sharing, grouping) so the single structure is seen to hold them all; name division as undoing multiplication
Extending Table PatternsSkip-counts or guesses 8×7 rather than deriving it from the known 8×5 and 8×2Next step: Split an array into 8×5 and 8×2 so the derivation is visible; connect it to the distributive idea they can see
