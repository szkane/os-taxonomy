🎯 What you’ll learn

  • 📏Measurable Attributes of Objects — Describe and identify measurable attributes of objects such as length, height, weight, and capacity; use comparative language (longer, shorter, heavier, lighter, more, …
  • 📏Ordering Events in Time — Sequence events in chronological order using language such as before, after, next, first, today, yesterday, tomorrow, morning, afternoon, evening
  • 📏Comparing Lengths & Heights — Compare two objects directly by length or height and describe the difference using language such as long, short, tall, longer, shorter, taller, double, half
  • 📏Comparing Capacity — Compare and describe capacity and volume using language such as full, empty, more than, less than, half full
  • 📏Measuring mass and weight (age 4+) — Compare two objects directly by mass or weight and describe the difference using language such as heavy, light, heavier than, lighter than
  • 📏Comparing durations — Use comparative language for time: quicker, slower, earlier, later

Common misconceptions (from teaching research)

Measurable Attributes of ObjectsUndifferentiated 'bigger': 'yes, A is taller so it is bigger, so it holds the most' — collapses height, size and capacity into one global quantityNext step: Pour to show a wide jar holding as much as or more than a taller bottle; narrate the attributes separately ('this one is taller, but this one holds more'); build the habit of naming which attribute a question asks about before answering.
Comparing Lengths & HeightsJudges by one endpoint — picks whichever object 'sticks out farthest' at one end without lining up the starting endsNext step: Line up both objects at one end first, then compare the other ends; use the mixed-up puppet who forgets to align so the child spots and fixes the error; ask 'where does each one START?'
Comparing CapacityHeight = amount — the taller liquid level (or taller glass) must have more, judged without pouringNext step: Pour both into identical beakers so the levels match — the amount didn't change with the shape; repeat with tall-thin vs short-wide until height stops being trusted.
Measuring mass and weight (age 4+)Judges the heavier object by size or appearance — 'the big box must be heavier because it's bigger'Next step: Have them heft the pair with eyes shut, then let the balance settle it — evidence over appearance; repeat with several small-heavy / big-light pairs so size is repeatedly wrong.
Comparing durationsJudges duration by speed or distance, not elapsed time — the faster/further event 'took longer', or slower means less timeNext step: Compare same-distance events with a shared start and a visible timer so duration is separated from speed; narrate 'slower over the same way means MORE time'.

Try at home (predict–observe–explain)
