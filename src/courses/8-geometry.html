📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is advancing their understanding of shapes and space — working with coordinates on grids, identifying different types of angles, exploring symmetry, and classifying shapes by their properties.

Common misconceptions (from teaching research)

Types of anglesThe angle with the longest lines is the biggest ('longer arms mean a bigger angle')Next step: Overlay the trapped pair vertex-on-vertex with one arm aligned so the narrow opening visibly folds inside the wide one; re-sort by opening and return to the right-angle benchmark.
Classifying quadrilateralsExclusive/partition thinking: 'a square is not a rectangle — they're two different shapes' (each shape belongs in exactly one box)Next step: Build a rectangle property checklist together and test the square against it item by item; use a nested Venn so the child sees the square can sit inside 'rectangle' without leaving 'square'. Reteach in place — this is the target concept.
First Quadrant CoordinatesReversal — reads/writes the vertical number before the horizontal ('up before across'), so A is given as (4,2) and B as (2,4).Next step: Reinstate 'along the corridor, then up the stairs' (x = across, first); tie the first number to the x-axis by name; practise placing a point and checking the along-then-up path.
Coordinates (age 8+)Reversal when plotting — plots the fourth vertex (or reads a given one) up-before-across, placing (5,1) at 1-across-5-up.Next step: Return to along-then-up plotting from the origin, tying the first number to the x (across) axis; plot (5,1) and (1,5) together to show they differ.
Transformations on a gridCalls the rotation a reflection (or vice versa) without checking senseNext step: Ask 'does the shape read the same way round or the mirror way round?' Establish that only reflection reverses sense; re-decide from that check.
Nets of 3-D ShapesBelieves only the familiar cross/T net makes a cube ('that's how a cube is always made'), so rejects valid non-standard nets and trusts anything resembling the prototypeNext step: Fold the rejected staircase physically to show it closes, then unfold several different valid nets from the same cube so the child sees 'there are eleven, not one'

Try at home (predict–observe–explain)

Show two angles: A with short arms and a wide opening, B with long arms and a narrow opening. Ask the child to PREDICT which is the bigger angle and WHY before anything is moved. Then overlay them vertex-on-vertex with one arm aligned so B's second arm falls inside A's. …

Activity ideas

  • Order the baited angles, then overlay to check
  • Sweep a hinge through acute, right and obtuse
  • Hunt and colour-sort angles inside shapes
  • Predict-then-check: short wide angle vs long narrow angle
