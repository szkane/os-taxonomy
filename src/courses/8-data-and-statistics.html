📖 Goals, common misconceptions & printable ideas

Learning goal

Your child is learning to collect information and present it visually using charts and graphs, then use these displays to solve problems and answer questions about the data.

Common misconceptions (from teaching research)

Scaled picture and bar graphsIgnores the scale/key and reads each symbol or square as one unitNext step: Read the key aloud first; overlay the count each symbol carries; re-read via multiplication by the scale
Bar graphsChooses the wrong representation for the data type — draws a joined line for discrete categories, or separated bars for continuous time dataNext step: Sort the data as counted-categories vs measured-over-time first; counted → bars with gaps, measured-over-time → joined line; reconnect to the discrete/continuous vocabulary

Activity ideas

  • Flip the scale: watch the same bars change value
  • Reading values between the marks
  • Two-step problems as two reads then combine
  • Construct a scaled graph from a frequency table
