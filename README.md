# PYP Marble Courses — an AI-generated IB PYP practice-site DEMO

> **This is a DEMO, not a curriculum.** The [`src/`](src/) folder is a fully
> playable online practice site for children aged 4–10, generated by AI coding
> on top of the [Marble Skill Taxonomy](https://github.com/withmarbleapp/os-taxonomy)
> and the [ib-pyp-html5-generator](https://github.com/szkane/ib-pyp-html5-generator)
> skill. It exists to show what is now possible — and to invite parents and
> teachers to build **their own** personalized version for their child.
>
> 🇨🇳 中文说明见 [README.zh-CN.md](README.zh-CN.md)

> **About this fork:** the upstream repository
> ([withmarbleapp/os-taxonomy](https://github.com/withmarbleapp/os-taxonomy))
> is the open **Marble Skill Taxonomy** — an open, structured graph of what
> children learn: 1,838 micro-topics, 3,878 prerequisite edges, 9 subjects,
> curriculum-standard alignments and teaching research. That data is unchanged
> in this fork; everything in [`src/`](src/) and [`tools/`](tools/) is new.

## What you are looking at

A static site (`src/`) with **317 playable course pages** — one for every
primary-age (4–10) subject × topic-domain × age combination in the taxonomy
(176 curated clusters + 141 auto-derived drafts). Each course wraps real
interactive practice in an IB PYP inquiry frame:

- **Inquiry-cycle structure** — every course states its central idea and lines
  of inquiry; activities are phased 🔍 Explore → 💡 Understand → 🗂️ Word cards
  → ⚡ Practice → 🎯 Show what you know, with a journey chip that fills in as
  the child plays.
- **15 game engines over 17 animated canvas scenes** — concept labs with
  physical dials (fractions pizza, place-value blocks, number lines, circuits,
  probability spinners), sorting, timeline & life-cycle builders, sentence
  clinics, speed-sprint arcades, decision quests with meters, memory pairs,
  word builders, printable handwriting sheets, and a picture-book engine that
  models reading strategies.
- **Three 3D worlds** (Three.js) — a drag-the-Earth day/night simulator, a
  solar-system tour, and a pressure-driven volcano lab, each with
  band-tiered challenge cases.
- **A spiral curriculum by age band** — early (4–6) / mid (7–8) / upper (9–10)
  play the *same game types* but always on *their own* topics: a 5-year-old
  sorts animals into families, a 9-year-old sorts them into ecosystem roles; a
  7-year-old hops a number line to 1,000, a 10-year-old rounds-then-adjusts on
  a line to 10,000.
- **Child-first UX** — children see only the stage; adult framing lives behind
  a "Grown-ups" panel. Read-aloud TTS with karaoke-style follow-along
  highlighting, dashed-underline vocabulary popovers, no answer leaks, no
  accounts, no tracking, offline-first.

## Try it

```bash
npm run build:site   # regenerates src/ from data/ and validates all content
npm run serve:site   # serves src/ on http://127.0.0.1:4173
```

Open the hub, pick a subject and an age, and play. The build is
self-validating: `tools/validate-content.mjs` machine-checks everything a
child can see — every authored sentence, quiz bank, and lab case (no
pre-solved cases, no unreachable dial targets, no identical content served to
different ages) — and fails the build on violation.

`src/` is plain static files, so it deploys anywhere: a GitHub Pages workflow
(`.github/workflows/deploy-pages.yml`) and a Cloudflare Pages config
(`wrangler.toml`) are included.

```
data/teaching-research.json 1,049 teaching-research records
        │
        ▼

                             representations, child-language glosses, game configs
tools/lib/band-modes.mjs     per-age-band interactive content (spiral curriculum)
tools/lib/lab-cases.mjs      per-age-band lab challenge cases
        ▼
tools/build-site.mjs         derives 317 static course pages: inquiry framing,
                             engines, flashcards from each age's own topics,
                             independent mission checks
        ▼
tools/validate-content.mjs   machine-checks all child-facing content
        ▼
src/                         the demo: static, offline-first, zero accounts
```

The taxonomy underneath — **1,838 micro-topics, 3,878 prerequisite edges,
9 subjects** — is
**[withmarbleapp/os-taxonomy](https://github.com/withmarbleapp/os-taxonomy)**;
this repo is a fork of it. The page shell, IB PYP framing, and interaction
patterns come from
**[szkane/ib-pyp-html5-generator](https://github.com/szkane/ib-pyp-html5-generator)**.

## The actual point: build YOUR child's version

Every child's weak spots are different, and no static demo can address them —
that was never the goal. The goal is to show that the ingredients for
personalized tutoring now fit on one machine:

1. **The learning graph.** The taxonomy decomposes primary school into
   fine-grained micro-topics with prerequisites, age ranges, and mastery
   evidence — so "fractions" stops being a vague worry and becomes a list of
   concrete, checkable skills, plus everything each one builds on.
2. **The generator.** The ib-pyp-html5-generator skill encodes how to turn a
   learning goal into a polished, self-contained interactive lesson — and this
   repo demonstrates it scaled to an entire site.
3. **AI coding.** This demo was produced by AI agents, not an engineering team.

A workflow we suggest to parents and teachers:

- Start from the child's **real school evidence** — the report card, the marked
  homework, the topic that keeps coming back wrong.
- Find those topics in `data/topics.json` (plain JSON — just ask an AI to
  search them), and follow the prerequisite edges to see what to consolidate
  first.
- Ask your AI coding assistant to generate a targeted course for exactly those
  topics, using the ib-pyp-html5-generator skill and this repo's `tools/` as
  the working pattern: one lesson on the shaky concept, with the
  representations and difficulty your child needs.
- Iterate from real use — what confused them, what they asked for. That loop
  (evidence → topic → generated practice → observation) is the personalization
  no boxed product can ship.

This demo is the existence proof. Your personalized version should not look
like this repo; it should look like your child.

## Repository layout

```
data/                 the Marble Skill Taxonomy (topics, clusters, research)
tools/                build + validation pipeline (plain Node, no framework)
  lib/mapping.mjs         per-domain pedagogy & game content (source of truth)
  lib/band-modes.mjs      per-age-band interactive content (spiral curriculum)
  lib/lab-cases.mjs       per-age-band lab challenge cases
  build-site.mjs          data → 317 static course pages
  validate-content.mjs    child-facing content machine checks (build gate)
src/                  the generated demo site (only assets/ is hand-edited)
docs/                 design docs, pedagogy audit, deployment notes
.agents/…/marble-builder             the lesson-design skill (in this repo)
~/.agents/skills/ib-pyp-html5-generator   the page-shell skill
```
